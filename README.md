# TAJ STORE

Маркетплейси онлайн барои Тоҷикистон — харидорон, фурӯшандагон ва маъмурият дар як ҷо.

## Имкониятҳо
- Каталог, ҷустуҷӯ (матн, овоз, акс), категорияҳо, муқоиса, дӯстдошта
- Сабад аз рӯи мағозаҳо; ҳар мағоза фармоиши алоҳида
- Пардохт ба корти фурӯшанда (Алиф, Эсхата, Душанбе Сити, Ориёнбонк ва ғ.) бо санҷиши чек, ё нақд ҳангоми гирифтан
- «Гирифтам», баргардонӣ ва баҳс, огоҳии паст шудани нарх
- Панели фурӯшанда: маҳсулот, анбор, фармоишҳо, аксия ва баннерҳо, купонҳо, даромад, чат
- Панели Admin: корбарон, мағозаҳо, маҳсулот, категорияҳо, пардохтҳо, аксия ва баннерҳо, дастгирӣ, ҳисобот
- Забонҳо: тоҷикӣ, русӣ, англисӣ · Асъор: сомонӣ · Ранг: кремӣ-тиллоӣ / сафед / торик

## Кушодан
Файли `index.html`-ро дар браузер кушоед.

## Ҳолат
Ҳоло ҳамаи маълумот дар браузери корбар нигоҳ дошта мешавад. Қадами навбатӣ — сервер ва базаи маълумот, то фармоиш, чат ва пардохт байни дастгоҳҳо кор кунанд.
