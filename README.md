# TAJ STORE

Маркетплейси онлайн барои Тоҷикистон — харидорон, фурӯшандагон ва маъмурият дар як ҷо.

## Имкониятҳо
- Каталог, ҷустуҷӯ (матн, овоз, акс), категорияҳо, муқоиса, дӯстдошта
- Сабад аз рӯи мағозаҳо; ҳар мағоза фармоиши алоҳида
- Пардохт ба корти фурӯшанда (Алиф, Эсхата, Душанбе Сити, Ориёнбонк ва ғ.) бо санҷиши чек, ё нақд ҳангоми гирифтан
- «Гирифтам», баргардонӣ ва баҳс, огоҳии паст шудани нарх
- Чати зинда байни харидор ва фурӯшанда, дастгирии TAJ STORE (ҷавобро танҳо одам медиҳад)
- Панели фурӯшанда: маҳсулот, анбор, фармоишҳо, аксия ва баннерҳо, купонҳо, даромад, чат
- Панели Admin: корбарон, мағозаҳо, маҳсулот, категорияҳо, пардохтҳо, аксия ва баннерҳо, дастгирӣ, ҳисобот
- Забонҳо: тоҷикӣ, русӣ, англисӣ · Асъор: сомонӣ · Ранг: кремӣ-тиллоӣ / сафед / торик

## Сервер (Supabase)
- Минтақа: Frankfurt (eu-central-1)
- Ворид шудан бо рақами телефон ва рамз (камаш 6 аломат). **Аввалин касе, ки сабт мешавад, Admin мешавад.**
- Маълумот: `supabase/migrations/` (ҷадвалҳо ва қоидаҳои дастрасӣ — RLS), `supabase/seed.sql` (категорияҳо ва нархи расонидан)
- Бақайдгирӣ: `supabase/functions/register`
- Аксҳо: Storage, bucket `img`
- Барнома тағйиротро ҳар чанд сония аз сервер мегирад (дар чат — ҳар 2,5 сония)

Қоидаҳои асосии амният (дар худи база):
- харидор танҳо фармоиш, чат ва профили худашро мебинад;
- фурӯшанда танҳо мағоза, маҳсулот ва фармоишҳои мағозаи худашро идора мекунад; маҳсулоти нав то тасдиқи Admin пинҳон аст;
- мағозаро танҳо Admin тасдиқ ё баста мекунад;
- ҳеҷ кас аз барнома маълумотро пурра нест карда наметавонад (танҳо нишонаи «нест шуд»).

## Кушодан
Файли `index.html`-ро дар браузер кушоед (интернет лозим аст).
Барои санҷиши бе сервер: `localStorage.setItem('taj-local','1')` ва саҳифаро нав кунед.
